# Tier 1 Agent (P2a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the manager a read-only SSH path to a peer for the things GraphQL does not expose, without installing a plugin on that peer and without any verb that can change it.

**Architecture:** A Tier 1 read is an existing `collector.Domain` with a different transport. `Domain` gains `transport` and `min_tier`; `run_cycle` picks `post_fn` or `exec_fn` and builds the same `Result`, so per-domain error isolation, retained payloads and the staleness labelling are inherited rather than rebuilt. On the peer, `agent-exec` is a stateless stdlib-Python script invoked by sshd as a forced command, reading one JSON envelope on stdin.

**Tech Stack:** Python 3.11 stdlib only (daemon and agent), PHP 8.2 (`SQLite3`, never `pdo_sqlite`), OpenSSH client on the manager, SQLite. No new dependency on either side.

**Spec:** `docs/superpowers/specs/2026-08-30-tier1-agent-design.md`

## Global Constraints

- **Python 3.11, stdlib only.** No pip, no vendored modules, in the daemon, the agent, or their tests. CI pins 3.11 and is the authority.
- **No test may touch a network, an `ssh` binary, or a live box.** Fixtures only.
- **Write LF always** — `open(path, 'w', newline='')`. CRLF is a syntax error on the box and git normalises on commit, so CI stays green while the local suite breaks.
- **No secret in a log line, a response, a URL, or the DOM.** `gqlclient.scrub` exists for this; the agent path uses it too.
- **Every subprocess call is an argv list.** No shell, no string interpolation, on either side.
- **No verb in P2a writes anything.** Enforced structurally by Task 5's assertion.
- **Both suites pass before any commit:** `python -m unittest discover -s tests/python` and `bash tests/php/run.sh`. JS suites run on the host: `node tests/js/*.mjs` (run.sh in the php docker image skips them).
- **Docs move in the same commit as the change** (CONTRIBUTING.md).

## Ambiguity resolved from the spec

The spec's §4 step 3 says the installer "fetch[es] `agent-exec` to
`/boot/config/plugins/unraid-manager/`" without saying from where. Three options
were possible: an unauthenticated URL on the manager, a GitHub raw fetch, or the
script embedded in the one-liner.

**Resolved: embedded, base64, in the one-liner.** An unauthenticated endpoint on
the manager is a new attack surface for a project whose whole posture is that a
peer trusts almost nothing; a GitHub fetch needs internet on the peer and lets
the installed agent drift from the manager that printed the command. Embedding
makes the agent's version exactly the manager's version at enrollment, and adds
no endpoint and no network dependency. The cost is a ~6 KB paste, which is the
same shape as every other paste in this project's workflow.

**If Joe prefers a different answer, this is the one decision in the plan worth
changing before Task 8 — everything before it is unaffected.**

```python
#!/usr/bin/env python3
"""Unraid-Manager Tier 1 agent. Invoked by sshd as a forced command.

Stateless: writes nothing, creates nothing, keeps nothing between calls.

One JSON envelope in on stdin, one JSON object out on stdout. Stdin rather
than argv on purpose - with a forced command, whatever the client typed
arrives in $SSH_ORIGINAL_COMMAND as an attacker-shaped string. Reading the
body on stdin means that variable is never parsed, never split, never
expanded. It is ignored, and a test asserts this file does not name it.

The allowlist IS the authorization model. An unknown verb exits non-zero
having run nothing.
"""
import json
import socket
import sys

AGENT_VERSION = '2026.08.30'


def hello(args):
    return {'version': AGENT_VERSION, 'hostname': socket.gethostname(),
            'verbs': sorted(VERBS)}


def _no_args(args):
    """Accepts an empty argument set and rejects anything else."""
    if args:
        raise ValueError('this verb takes no arguments')
    return {}


VERBS = {
    'agent.hello': (_no_args, hello),
}


def _fail(verb, code, message):
    return json.dumps({'ok': False, 'verb': verb, 'error': message, 'code': code})


def handle(text, table):
    """Pure: envelope text in, one JSON line out. Never raises."""
    try:
        envelope = json.loads(text)
    except Exception:
        return _fail(None, 'BAD_ENVELOPE', 'body is not JSON')
    if not isinstance(envelope, dict):
        return _fail(None, 'BAD_ENVELOPE', 'body is not an object')
    verb = envelope.get('verb')
    if not isinstance(verb, str) or not verb:
        return _fail(None, 'BAD_ENVELOPE', 'no verb')
    if verb not in table:
        return _fail(verb, 'UNKNOWN_VERB', 'unknown verb')

    validate, run = table[verb]
    args = envelope.get('args') or {}
    if not isinstance(args, dict):
        return _fail(verb, 'BAD_ARGS', 'args is not an object')
    try:
        args = validate(args)
    except ValueError as exc:
        return _fail(verb, 'BAD_ARGS', str(exc))
    except Exception as exc:                       # noqa: BLE001
        # NOT just ValueError. A validator does real work - Task 2's device
        # check reads /sys/block - and an OSError escaping here escapes main()
        # too, so the peer answers a traceback on stderr and NOTHING on stdout.
        # The manager then sees an unparseable empty reply instead of BAD_ARGS,
        # which is the exact failure the envelope contract exists to prevent.
        return _fail(verb, 'BAD_ARGS', '%s: %s' % (type(exc).__name__, exc))
    try:
        return json.dumps({'ok': True, 'verb': verb, 'data': run(args)})
    except Exception as exc:                       # noqa: BLE001
        return _fail(verb, 'RUN_FAILED', '%s: %s' % (type(exc).__name__, exc))


def main():
    reply = handle(sys.stdin.read(), VERBS)
    sys.stdout.write(reply)
    sys.stdout.write('\n')
    return 0 if json.loads(reply)['ok'] else 1


if __name__ == '__main__':
    sys.exit(main())
```

```python
class TestReadVerbs(unittest.TestCase):
    def reply(self, text):
        return json.loads(agent.handle(text, agent.VERBS))

    def test_a_device_that_is_not_ours_is_refused(self):
        # Validated against the agent's OWN enumeration, not a pattern. A regex
        # still admits a device that is not there, and smartctl on it hangs.
        agent.devices = lambda: ['/dev/sda']
        got = self.reply('{"verb": "smart.attributes",'
                         ' "args": {"devices": ["/dev/nope"]}}')
        self.assertFalse(got['ok'])
        self.assertEqual('BAD_ARGS', got['code'])

    def test_a_traversal_argument_is_refused_the_same_way(self):
        agent.devices = lambda: ['/dev/sda']
        for bad in ('/etc/shadow', '../../etc/shadow', '/dev/sda; rm -rf /',
                    '/dev/sda\n/dev/sdb'):
            got = self.reply(json.dumps({'verb': 'smart.attributes',
                                         'args': {'devices': [bad]}}))
            self.assertFalse(got['ok'], bad)
            self.assertEqual('BAD_ARGS', got['code'], bad)

    def test_no_devices_argument_means_all_of_them(self):
        # One call per node per cycle, never one per disk: Golem has 22, and a
        # per-device verb would open 22 SSH connections every slow cycle.
        agent.devices = lambda: ['/dev/sda', '/dev/sdb']
        agent._run = lambda argv: 'ran ' + argv[-1]
        got = self.reply('{"verb": "smart.attributes"}')
        self.assertEqual(['/dev/sda', '/dev/sdb'], sorted(got['data']))

    def test_one_unreadable_disk_does_not_lose_the_others(self):
        # Fail closed per device, never per node: a single dead drive must not
        # blank the SMART view of every healthy one beside it.
        agent.devices = lambda: ['/dev/sda', '/dev/sdb']

        def boom(argv):
            if argv[-1] == '/dev/sda':
                raise OSError('I/O error')
            return 'fine'
        agent._run = boom
        got = self.reply('{"verb": "smart.attributes"}')
        self.assertTrue(got['ok'])
        self.assertIsNone(got['data']['/dev/sda'])
        self.assertEqual('fine', got['data']['/dev/sdb'])

    def test_mounts_are_returned_raw(self):
        # Raw on purpose: a parse bug in the agent costs twenty paste sessions,
        # in the manager it costs one file patch.
        got = self.reply('{"verb": "mounts.list"}')
        self.assertTrue(got['ok'])
        self.assertIn('proc_mounts', got['data'])

    def test_every_verb_is_declared_by_hello(self):
```

```python
import os
import subprocess

RUN_TIMEOUT = 30


def _run(argv):
    """Run one command as an argv list. Never a shell, never a string."""
    done = subprocess.run(argv, capture_output=True, text=True, timeout=RUN_TIMEOUT)
    return done.stdout


def devices():
    """This box's block devices, from the kernel rather than from a guess."""
    return sorted('/dev/' + name for name in os.listdir('/sys/block')
                  if name.startswith(('sd', 'nvme', 'hd')))


def _validate_devices(args):
    """Refuse anything that is not one of OUR devices.

    A pattern like ^/dev/sd[a-z]+$ still admits a device that is not there, and
    smartctl on it blocks until the timeout. Asking "is this one of mine" has no
    clever-input case: the answer comes from /sys/block, not from the caller.
    """
    extra = set(args) - {'devices'}
    if extra:
        raise ValueError('unexpected arguments: %s' % ', '.join(sorted(extra)))
    wanted = args.get('devices')
    mine = devices()
    if wanted is None:
        return {'devices': mine}
    if not isinstance(wanted, list):
        raise ValueError('devices must be a list')
    unknown = [d for d in wanted if d not in mine]
    if unknown:
        raise ValueError('not a device on this node: %s' % ', '.join(map(str, unknown)))
    return {'devices': wanted}


def smart_attributes(args):
    out = {}
    for device in args['devices']:
        try:
            out[device] = _run(['smartctl', '--json=c', '-a', device])
        except Exception:                          # noqa: BLE001
            # None, never '' - unreadable is not the same fact as empty, and a
            # single dead drive must not blank every healthy one beside it.
            out[device] = None
    return out


def mounts_list(args):
    with open('/proc/mounts', encoding='utf-8') as fh:
        return {'proc_mounts': fh.read()}


def pool_balance(args):
    btrfs = {}
    for line in mounts_list({})['proc_mounts'].splitlines():
        parts = line.split()
        if len(parts) > 2 and parts[2] == 'btrfs':
            try:
                btrfs[parts[1]] = _run(['btrfs', 'filesystem', 'usage', parts[1]])
            except Exception:                      # noqa: BLE001
                btrfs[parts[1]] = None
    try:
        zfs = _run(['zpool', 'status'])
    except Exception:                              # noqa: BLE001
        # No zpool binary is not an error - it is a box without ZFS. None says
        # "we did not read it", which is the honest answer either way.
        zfs = None
    return {'btrfs': btrfs, 'zfs': zfs}
```

```python
"""The Tier 1 transport: ssh to a peer's forced command.

Shaped like gqlclient on purpose. `ssh_argv` and `exec_response` are pure, so
the whole classification story is testable on a machine with no ssh binary -
the same reason `parse_response` is testable with no socket.
"""
import json

SSH_TIMEOUT = 30


class AgentUnreachable(Exception):
    """We could not get an answer out of the peer at all."""


class AgentRefused(Exception):
    """The agent answered, and said no."""


class VerbUnsupported(AgentRefused):
    """The agent answered and does not have that verb.

    A subclass because it IS a refusal, but the manager treats it as a third
    state: 'needs a newer agent' is not an error, and rendering it as one turns
    an ordinary version gap into a fault the operator chases.
    """


def exec_response(returncode, stdout, stderr):
    """Classify one ssh invocation. Pure."""
    text = (stdout or '').strip()
    if not text:
        return _unreachable(returncode, stderr)
    try:
        reply = json.loads(text)
    except Exception:
        # Not our agent: an MOTD, a banner, or a different forced command.
        return _unreachable(returncode, stderr or text[:200])
    if not isinstance(reply, dict) or 'ok' not in reply:
        return _unreachable(returncode, 'reply is not an agent envelope')
    if reply.get('ok'):
        return reply.get('data')
    code = reply.get('code')
    message = reply.get('error') or code or 'the agent refused'
    if code == 'UNKNOWN_VERB':
        raise VerbUnsupported(message)
    raise AgentRefused(message)


def _unreachable(returncode, detail):
    raise AgentUnreachable('ssh exited %s: %s'
                           % (returncode, (detail or 'no output').strip()[:200]))
```

```python
import os
import subprocess

SSH_PORT = 22
AGENT_PATH = '/boot/config/plugins/unraid-manager/agent-exec'


def key_path(keys_dir, node_id):
    return os.path.join(keys_dir, node_id + '.ssh')


def known_hosts_path(keys_dir):
    return os.path.join(keys_dir, 'known_hosts')


def ssh_argv(node, keyfile, known_hosts, timeout):
    """The exact argv. Pure, so the whole option set is a test, not a habit."""
    return [
        'ssh',
        '-i', keyfile,
        '-p', str(SSH_PORT),
        '-o', 'BatchMode=yes',
        '-o', 'PasswordAuthentication=no',
        '-o', 'StrictHostKeyChecking=yes',
        '-o', 'UserKnownHostsFile=' + known_hosts,
        '-o', 'ConnectTimeout=%d' % max(1, int(timeout)),
        '-o', 'ForwardAgent=no',
        '-o', 'ForwardX11=no',
        '-N', '-T',
        # `--` before the destination: an address is data. Without it an address
        # beginning with a dash is read by ssh as an option, and ProxyCommand is
        # an option that runs a program.
        '--',
        'root@' + str(node['address']),
    ]


def _run_ssh(argv, stdin_text, timeout):
    done = subprocess.run(argv, input=stdin_text, capture_output=True,
                          text=True, timeout=timeout)
    return done.returncode, done.stdout, done.stderr


def exec_agent(node, verb, args, timeout, keys_dir, run_fn=None):
    """Run one verb on one peer. Raises AgentUnreachable/AgentRefused."""
    run_fn = run_fn or _run_ssh
    envelope = json.dumps({'verb': verb, 'args': args or {}})
    argv = ssh_argv(node, key_path(keys_dir, node['id']),
                    known_hosts_path(keys_dir), timeout)
    try:
        returncode, stdout, stderr = run_fn(argv, envelope, timeout)
    except Exception as exc:                       # noqa: BLE001
        raise AgentUnreachable('%s: %s' % (type(exc).__name__, exc))
    return exec_response(returncode, stdout, stderr)
```

```python
import agentclient


def parse_smart(data):
    """`data` is {device: raw smartctl stdout or None}.

    None is preserved, never dropped and never coerced to {}: a drive we could
    not read is a different fact from a drive that is not there, and the Disks
    tab already knows how to render the difference.
    """
    disks = {}
    for device, raw in (data or {}).items():
        disks[device] = None if raw is None else json.loads(raw)
    return {'count': len(disks), 'disks': disks}


def parse_mounts(data):
    rows = []
    for line in (data or {}).get('proc_mounts', '').splitlines():
        parts = line.split()
        if len(parts) >= 3:
            rows.append({'source': parts[0], 'target': parts[1], 'fstype': parts[2]})
    return {'count': len(rows), 'mounts': rows}


def collect_agent(exec_fn, node, domain):
    """Run one agent domain against one node. Never raises.

    The same fail-closed rule as collect(): could not READ it is `unknown`, the
    peer answered and failed is `error`. One extra status this path can produce
    - `unsupported` - because an agent older than the manager is a version gap,
    not a fault, and the two must not arrive looking alike.
    """
    try:
        data = exec_fn(node, domain.query, {}, domain.timeout)
    except agentclient.VerbUnsupported:
        return Result(domain.name, 'unsupported', None,
                      'this node needs a newer agent for %s' % domain.query, [])
    except agentclient.AgentRefused as exc:
        return Result(domain.name, 'error', None, str(exc), [])
    except agentclient.AgentUnreachable as exc:
        return Result(domain.name, 'unknown', None, str(exc), [])

    try:
        return Result(domain.name, 'ok', domain.parse(data), None, [])
    except Exception as exc:                       # noqa: BLE001
        return Result(domain.name, 'error', None,
                      'could not read the %s reply: %s: %s'
                      % (domain.name, type(exc).__name__, exc), [])
```
